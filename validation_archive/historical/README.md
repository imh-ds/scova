# Historical simulation archive — not for presentation

This Git-tracked archive retains exploratory and superseded simulation outputs so prior development decisions can be audited without mixing them into manuscript or product evidence.

## Contents

- `cf-comparative-wip/`: SCOVA-CF v1/v2/v3 pilots and local shard rehearsals. These have incomplete replication denominators, precede a frozen final design, or exist only to validate workflow mechanics.
- `../cf-v9/`: preserved historical randomized-profile evidence. It remains necessary to read legacy artifacts but is not evidence for the current observational SCOVA-CF product claim.
- `../stage4-v4/`: local scratch archive for experimental regular-SCOVA Stage 4 validation material. It remains deliberately outside the presentation index.
- `docs/historical/`: retired SCOVA-CF qualification protocols, workflows, and governance documents.

Do not pool historical and presentation artifacts, substitute a pilot for a final study, or use this archive to claim observational causal certification.
