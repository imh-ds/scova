# Simulation evidence index

This directory is the starting point for results that may support public technical documentation or a manuscript. It intentionally separates completed, frozen evidence from historical exploratory material.

- [`presentation/scova/`](presentation/scova/) contains the current regular-SCOVA release examples and promotion summaries. Some finite-grid/transport features remain experimental; the folder is evidence of the recorded behavior, not a blanket production claim.
- [`presentation/scova-cf/`](presentation/scova-cf/) contains the completed, frozen SCOVA-CF comparative simulations. The v2 and v3 evidence sets are separate and must not be pooled.
- [`../validation_archive/historical/`](../validation_archive/historical/) contains prior pilots, rehearsal shards, and retired qualification work. It is retained for audit and learning, not presentation.

Every observational result remains conditional on the analyst's causal assumptions. Simulation evidence does not prove exchangeability, positivity, or causal validity in an applied dataset.
