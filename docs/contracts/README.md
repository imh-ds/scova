# Methodological contracts

Contracts state what an estimator targets, which assumptions belong to the
analyst, what diagnostics can and cannot establish, and how result statuses
should be interpreted.

- [`statistical_contract.md`](statistical_contract.md) — stable fixed-target
  SCOVA estimand and simultaneous inference.
- [`scova_cf_methodological_contract.md`](scova_cf_methodological_contract.md)
  — SCOVA-CF modes, qualification boundaries, and diagnostics.

The contracts are normative. Examples and implementation details may evolve,
but a release must not claim more than these documents permit.
