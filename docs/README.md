# SCOVA documentation

This directory is the public documentation index for SCOVA. Start with the
[methodology decision log](methodology_decision_log.md) for the consolidated
record of design choices, evidence boundaries, and release decisions.

| Area | Use it for |
| --- | --- |
| [`api/`](api/README.md) | Public estimator and design API behavior |
| [`contracts/`](contracts/README.md) | Normative estimands, assumptions, and result-status rules |
| [`theory/`](theory/README.md) | Mathematical definitions and theory-to-code correspondence |
| [`reproducibility/`](reproducibility/README.md) | Re-running validation and interpreting release evidence |
| [`methodology_decision_log.md`](methodology_decision_log.md) | Chronological decisions and the current operating position |
| [`archive/`](archive/README.md) | Map to historical documents retained locally, but not published |

The public documents describe the supported package surface and its explicit
limits. Experimental and directional material is labeled as such; historical
documents must not be used as current release authority.
